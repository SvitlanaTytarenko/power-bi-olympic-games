# Power BI — Olympic Games 1896–2016

## 📌 Опис проєкту
Аналітичний проєкт у Power BI, присвячений аналізу участі спортсменів
та медалей Олімпійських ігор за період 1896–2016 років.

## 🎯 Мета
- проаналізувати динаміку участі спортсменів
- порівняти літні та зимові Олімпійські ігри
- дослідити гендерний баланс
- визначити країни-лідери за медалями

## 📊 Використані дані
Навчальна база даних з інформацією про:
- спортсменів
- країни
- види спорту
- медалі
- роки та сезони

## 🛠 Інструменти
- Power BI
- DAX
- Data modeling

- інтерактивний дашборд
- фінальна презентація з ключовими висновками
